### Make Authenticated GET Request (JavaScript)

Source: https://github.com/br-g/openf1/blob/main/documentation/pages/auth.html

Provides a JavaScript example using the Fetch API to make an authenticated GET request. It includes the 'Authorization: Bearer' header with the provided access token for API access.

```javascript
async function fetchDataWithToken(accessToken) {
    const apiUrl = "https://api.openf1.org/v1/sessions?year=2024"; // Example

    try {
        const response = await fetch(apiUrl, {
            method: "GET",
            headers: {
                "accept": "application/json",
                "Authorization": `Bearer ${accessToken}`,
            },
        });

        if (response.ok) {
            const data = await response.json();
            console.log(data);
            return data;
        } else {
            console.error("Error fetching data:", response.status, await response.text());
            return null;
        }
    } catch (error) {
        console.error("Network error or other issue:", error);
        return null;
    }
}

### Obtain OpenF1 API Access Token (JavaScript)

Source: https://github.com/br-g/openf1/blob/main/documentation/pages/auth.html

Provides a JavaScript example using the Fetch API to obtain an access token. It constructs URL parameters for credentials and sends a POST request, handling success and error responses.

```javascript
async function getAccessToken() {
    const tokenUrl = "https://api.openf1.org/token";
    const params = new URLSearchParams();
    params.append("username", "YOUR_USERNAME");
    params.append("password", "YOUR_PASSWORD");

    try {
        const response = await fetch(tokenUrl, {
            method: "POST",
            headers: {
                "Content-Type": "application/x-www-form-urlencoded",
            },
            body: params,
        });

        if (response.ok) {
            const tokenData = await response.json();
            console.log("Access token:", tokenData.access_token);
            console.log("Expires in:", tokenData.expires_in, "seconds");
            return tokenData.access_token;
        } else {
            console.error("Error obtaining token:", response.status, await response.text());
            return null;
        }
    } catch (error) {
        console.error("Network error or other issue:", error);
        return null;
    }
}

// Example usage:
// getAccessToken().then(token => {
//     if (token) {
//         // Use the token
//     }
// });
```

### OpenF1 Race Control API Endpoint Reference

Source: https://github.com/br-g/openf1/blob/main/documentation/includes/_api_endpoints.md

Detailed documentation for the OpenF1 race control API endpoint, including available parameters, their types, and usage examples.

```APIDOC
GET https://api.openf1.org/v1/race_control

Description:
  Retrieves information about race control events, such as racing incidents, flags, and safety car periods.

Parameters:
  - date (string, optional): Filters results by date. Supports comparison operators like '>=', '<'. Example: `date>=2023-01-01`.
  - driver_number (integer, optional): Filters results by the driver's unique number. Example: `driver_number=1`.
  - flag (string, optional): Filters results by specific flag types. Example: `flag=BLACK AND WHITE`.
  - meeting_key (integer, optional): Filters results by the unique identifier for the meeting.
  - session_key (integer, optional): Filters results by the unique identifier for the session.

Example URL:
  https://api.openf1.org/v1/race_control?flag=BLACK AND WHITE&driver_number=1&date>=2023-01-01&date<2023-09-01

Response Structure (Example):
  [
    {
      "category": "Flag",
      "date": "2023-06-04T14:21:01+00:00",
      "driver_number": 1,
      "flag": "BLACK AND WHITE",
      "lap_number": 59,
      "meeting_key": 1211,
      "message": "BLACK AND WHITE FLAG FOR CAR 1 (VER) - TRACK LIMITS",
      "scope": "Driver",
      "sector": null,
      "session_key": 9102
    }
  ]

Response Fields:
  - category (string): The category of the race control event (e.g., "Flag").
  - date (string): The UTC date and time of the event in ISO 8601 format.
  - driver_number (integer): The unique number assigned to the driver involved.
  - flag (string): The specific flag displayed (e.g., "BLACK AND WHITE").
  - lap_number (integer, optional): The lap number during which the event occurred.
  - meeting_key (integer): The unique identifier for the F1 meeting.
  - message (string): A descriptive message about the race control event.
  - scope (string): The scope of the event (e.g., "Driver", "All").
  - sector (string, optional): The sector in which the event occurred.
  - session_key (integer): The unique identifier for the session.

Related Attributes:
  - date: The UTC date and time, in ISO 8601 format.
  - driver_number: The unique number assigned to an F1 driver.
  - meeting_key: The unique identifier for the meeting. Use `latest` to identify the latest or current meeting.
  - position: Position of the driver (starts at 1).
  - session_key: The unique identifier for the session. Use `latest` to identify the latest or current session.
```

### Request CSV Format via API Query Parameter

Source: https://github.com/br-g/openf1/blob/main/documentation/includes/_csv_format.md

To receive query results in CSV format instead of the default JSON, append the query parameter 'csv=true' to your API URL. This is useful for importing data into spreadsheet software. The example shows how to get all sessions for 2023 in CSV format.

```APIDOC
API Endpoint: /v1/sessions

Query Parameters:
  year: (integer) The year for which to retrieve sessions.
  csv: (boolean) Set to 'true' to receive results in CSV format instead of JSON.

Example Request URL:
https://api.openf1.org/v1/sessions?year=2023&csv=true

Description:
Appends the 'csv=true' parameter to the standard API request URL. This instructs the API to return the data in Comma Separated Values format, which is easily parsable by spreadsheet applications like Microsoft Excel. The default format is JSON.
```

### JavaScript MQTT Websocket Connection

Source: https://github.com/br-g/openf1/blob/main/documentation/pages/auth.html

Demonstrates connecting to OpenF1's MQTT broker using WebSockets in JavaScript with the mqtt.js library. It shows how to authenticate with an access token, subscribe to topics like 'v1/location' and 'v1/laps', and handle incoming messages and connection events.

```javascript
// In Node.js: npm install mqtt
// In Browser: <script src="https://unpkg.com/mqtt/dist/mqtt.min.js"></script>

// Assume 'accessToken' is a variable holding your obtained token
const accessToken = "YOUR_ACCESS_TOKEN";
const websocketUrl = "wss://mqtt.openf1.org:8084/mqtt";

const options = {
    username: "your_username_or_email@example.com", // Optional, can be any string
    password: accessToken // Access token is used as the password
};

const client = mqtt.connect(websocketUrl, options);

client.on('connect', function () {
    console.log('Connected to OpenF1 via Websockets');
    client.subscribe('v1/location', function (err) {
        if (!err) {
            console.log('Subscribed to v1/location');
        } else {
            console.error('Subscription error for v1/location:', err);
        }
    });
    client.subscribe('v1/laps', function (err) {
        if (!err) {
            console.log('Subscribed to v1/laps');
        } else {
            console.error('Subscription error for v1/laps:', err);
        }
    });
    // client.subscribe('#'); // Subscribe to all topics
});

client.on('message', function (topic, message) {
    console.log(`Received on ${topic}: ${message.toString()}`);
    // const data = JSON.parse(message.toString());
    // Process data
});

client.on('error', function (error) {
    console.error('MQTT Connection Error:', error);
});

client.on('close', function () {
    console.log('MQTT Connection closed');
});

client.on('offline', function() {
    console.log('MQTT Client is offline');
});

client.on('reconnect', function() {
    console.log('MQTT Client is attempting to reconnect');
});

```

### Python MQTT Connection to OpenF1

Source: https://github.com/br-g/openf1/blob/main/documentation/pages/auth.html

Demonstrates how to establish a connection to the OpenF1 MQTT broker using the paho-mqtt library. It includes authentication with an OAuth2 access token, setting up TLS, subscribing to topics like 'v1/location' and 'v1/laps', and handling incoming messages. Requires the 'paho-mqtt' library and a valid access token.

```Python
import paho.mqtt.client as mqtt
import ssl
import json

# Assume 'access_token' is a variable holding your obtained token
access_token = "YOUR_ACCESS_TOKEN"
mqtt_broker = "mqtt.openf1.org"
mqtt_port = 8883

# Optional: Provide a username. Can be an email or any non-empty string.
mqtt_username = "your_username_or_email@example.com"

def on_connect(client, userdata, flags, rc, properties=None):
    if rc == 0:
        print("Connected to OpenF1 MQTT broker")
        client.subscribe("v1/location")
        client.subscribe("v1/laps")
        # client.subscribe("#") # Subscribe to all topics
    else:
        print(f"Failed to connect, return code {rc}")

def on_message(client, userdata, msg):
    print(f"Received message on topic '{msg.topic}': {msg.payload.decode()}")
    # Example: data = json.loads(msg.payload.decode())

client = mqtt.Client(mqtt.CallbackAPIVersion.VERSION2)
client.username_pw_set(username=mqtt_username, password=access_token)
client.tls_set(cert_reqs=ssl.CERT_REQUIRED, tls_version=ssl.PROTOCOL_TLS_CLIENT)

client.on_connect = on_connect
client.on_message = on_message

try:
    client.connect(mqtt_broker, mqtt_port, 60)
    client.loop_forever() # Starts a blocking network loop
except Exception as e:
    print(f"Connection error: {e}")

```

### OpenF1 API Authentication and Real-time Data

Source: https://github.com/br-g/openf1/blob/main/documentation/pages/auth.html

Details on obtaining API access tokens and connecting to real-time data streams via MQTT and WebSockets. Includes token expiry information and connection endpoints.

```APIDOC
API Authentication:

1.  **Token Acquisition**:
    *   POST to `https://api.openf1.org/token`
    *   Requires `username` and `password` in `x-www-form-urlencoded` format.
    *   **Response**: JSON object containing `access_token`, `expires_in` (seconds), and `token_type`.
    *   Example Response:
        ```json
        {
            "expires_in": "3600",
            "access_token": "YOUR_ACCESS_TOKEN",
            "token_type": "bearer"
        }
        ```
    *   Tokens expire after 1 hour. Implement logic to refresh tokens.

2.  **Authenticated Requests**:
    *   Include the obtained `access_token` in the `Authorization` header as a Bearer token.
    *   Header format: `Authorization: Bearer YOUR_ACCESS_TOKEN`
    *   Example Request (GET sessions):
        ```bash
        curl -X 'GET' \
            'https://api.openf1.org/v1/sessions?year=2024' \
            -H 'accept: application/json' \
            -H 'Authorization: Bearer YOUR_ACCESS_TOKEN'
        ```

Real-time Data:

*   **Recommended Method**: Use MQTT or Websockets for efficient real-time data push.

*   **Connection Details**:
    *   **MQTT server**: `mqtt.openf1.org`
    *   **MQTT port (TLS/MQTTS)**: `8883`
    *   **Websockets URL (WSS for MQTT over Websockets)**: `wss://mqtt.openf1.org:8084/mqtt`
```

### Obtain OpenF1 API Access Token (Python)

Source: https://github.com/br-g/openf1/blob/main/documentation/pages/auth.html

Demonstrates how to request an API access token from the OpenF1 token endpoint using the Python 'requests' library. It sends username and password in the request body and handles the JSON response.

```python
import requests

token_url = "https://api.openf1.org/token"
payload = {
    "username": "YOUR_USERNAME",
    "password": "YOUR_PASSWORD"
}
headers = {
    "Content-Type": "application/x-www-form-urlencoded"
}

response = requests.post(token_url, data=payload, headers=headers)

if response.status_code == 200:
    token_data = response.json()
    print(f"Access token: {token_data.get('access_token')}")
    print(f"Expires in: {token_data.get('expires_in')} seconds")
else:
    print(f"Error obtaining token: {response.status_code} - {response.text}")
```
